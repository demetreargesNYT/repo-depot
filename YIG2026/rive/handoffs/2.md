## The 3D cube method (`cube3d.py`)

The signature of the crossword rooms (Mini, Midi, Crossword). Each moving cube or lid is modelled in 3D, moved, and every corner is projected back onto the drawing each frame. Faces are paths with keyed vertices (never scaled), so strokes stay 1.5; every face is a single solid light (`DFDBD7`) or black (`1F1F1F`) colour, never a grid; faces turned away are hidden on the frame they go edge-on.
- **Projection:** measured from the art, oblique, depth shifts a point by (-0.4000, -0.4663) per unit depth ("up and to the left"); all four Mini cubes share it. `PERSPECTIVE = 0.06` (one setting; front faces are exactly the art; receding faces taper about 5.7%). Rest poses match the art to within 0.074 px (asserted).
- **API:** `Cube(name, front_rect, depth_px)` with poses `turn`, `lid`, `door`, `slide`, `tip`, `dip`; `Face(...)`, `Fixed(...)`, `pattern(...)` (unused: faces are solid), `signed_area`, `rotate`/`turn_y`, `shape_lines`, `thin_keys(doc, anim, ids, protect, props)` (thins vertex keys to 0.3 art units; the Mini's worst deviation is 0.25 px), `ensure_keys` (restores keys at the edge of every rest so nothing creeps).
- **Things learned:** lids open to about 92 to 96°; past ~98° the free edge dips back and the jitter check reads a buzz. A closed lid must sit flush (0.000 px, asserted); any bounce on closing must stay inside the cube's outline (soft double tap, not a sliver). A fake-out crack holds 0.23 s or more (quicker reads as a buzz). A tip past ~22° trips the buzz check on the rear corners. The longest hidden stretch should stay near 1.2 s unless the brief says otherwise.
- **Cubes in the Mini** (after the 0.85 scale; phone crop x 560 to 935, y 0 to 812): top cube U (front x 788.5 to 870, y 590 to 671; the main stage), right stack R (x 870 to 951, cut on the right), front cube F (x 690 to 771.5, y 750 to 831; cut at the bottom), left box L (x 568 to 649, y 671 to 753, cut on the left). ## How I build and merge (the worker pattern)

- **The whole of `chapters/ch2/scene.rml` is generated.** `chapters/ch2/scripts/build.py` starts from the scene at 340b2c7 (`common.base_text()`, with the scene-name renames), then runs each room module in order: `python3 chapters/ch2/scripts/build.py --real bee mini strands daily midi connections wordle intro_c2s1 community` (this order; it refuses the real file without `--real`). Then `python3 tools/rooms_sheet.py ch2` and `npm run finesse 2 "<room>"`. An Editor edit in Rive would be lost by a rebuild: fold it into the room's script first.
- **Workers:** one general-purpose helper per room. The brief names the CLAUDE.md sections, the room's script, `common.py`, `sim.py`, `tools/ball_physics.py`, `strands.py`/`bee.py` as examples, the stills and the note text word for word, plus session notes (limits, the engineering contract). A worker edits only its own room's scripts (`<room>.py`, new `<room>_*.py`), builds into its own copy with `python3 chapters/ch2/scripts/build.py --out <folder> <rooms>` (never `--real`), runs `python3 tools/check.py <copy>` and `python3 tools/ball_speed.py <copy> "<Room>" --contacts`, looks at stills with `python3 tools/rive_still.py <copy path> <scene> <seconds ...>`, and reports (timeline, numbers, checks, what it could not do). Shared files (`common.py`, `sim.py`, `build.py`, `tools/`, `docs/`, `harness/`, `chapters/ch1`, `chapters/ch3`, `tools/ball_speed_accepted.json`) are off limits to workers.
- **Merging:** I run the real build, the rooms sheet and `npm run finesse 2 "<room>"` for each changed room, check with `git diff --stat` that other rooms did not change, open a still of the result, mark notes done with `note_done.py`, and commit by path. To merge one worker's room while others are mid-edit, `.cache/scratch.nosync/ch2/try/run_pinned.py` loads the other rooms' modules from `try/head-mods/` (copies of the committed scripts); it is written for the old `CH2_OUT=` form, so pass `--out`/`--real` as arguments instead.
- **Scratch:** `.cache/scratch.nosync/ch2/` (git-ignored): `mini3d-work`, `mini-loop*`, `community-work`, `bee-work`, `connections-work`, `shelf-wordle-work` (workers' copies), `try/` (sims and helpers), `stills/` (written by `rive_still.py`), `spin/` (the Spelling Bee storyboard), `compare_all.py` (lists every `rive_compare` difference grouped by kind), `same_intro.py`. Delete scratch only with `python3 tools/scratch_clean.py <path>`.
- **Accepted ball flags** live in `tools/ball_speed_accepted.json` (shared; Demetre's approval per entry): Shelf (as drawn), Wordle (7), Connections (2), Strands (the fling). It may still hold a stale Mini entry (turn-round at 4.47 s) that no longer applies.

## Rules that bit me this week

- Mark notes done only with `tools/note_done.py`; no inline Python. Commit as its own Bash call: `git commit -m "..." -- <paths>` (add new files with `git add <path>` first). Never `git add .`/`-A`, `git stash`, or force-push.
- No heredocs (`python3 - <<EOF`), no `$( )` or backticks, no `NAME=value` prefixes (use `--out`, not `CH2_OUT=`), no shell `for` loops: write a small script under `.cache/scratch.nosync/ch2/` and run it with `python3`.
- The raw `rive` command is denied. Render stills with `tools/rive_still.py`, measure sizes with `tools/rive_size.py`, push only with `tools/rive_push.py` (which takes and releases `.cache/rive-push.lock`; never create or delete the lock by hand). Open a still of your own work before you report it.
- Engineering contract: never add, rename or remove a scene, a setting or an enum value; keep the published copy waits (2.0 s first visit, 3.2 s with a lockup, 1.65 s room already built, 0.34 s within a room). A room's arrival must not change when only its loop is reworked; `python3 tools/compare_room.py ch2 <scene> --rev HEAD --frames 1-191` shows what differs.
- Ball rules that decided designs: 0.40 gravity; contacts keep 70 to 90% (flings only on pieces meant to fling); never stop dead on a landing (settle roll); squash maxima (gather 5%, landing 6%, stretch 3%, big earned landing 8%); never roll slowly off an edge in the physics sim (it snaps the ball onto the next surface; that caused the old Spelling Bee one-frame jump); keep the ball's top and moving pieces at or below y 425 unless a brief says otherwise.
- Report every Rive revision and GitHub commit in the next message after a push.
